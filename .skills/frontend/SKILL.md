# 🎨 Skill Local de Projeto — Frontend

Esta skill governa a camada visual, apresentação e interação do projeto ativo.

## 📌 Escopo e Responsabilidades
1. **Padrões de Interface:** Componentização limpa, separação de concerns e design responsivo.
2. **Manipulação do DOM e Estado:** Gerenciamento determinístico de estado de tela sem efeitos colaterais ocultos.
3. **Acessibilidade (a11y):** Marcação semântica com suporte a leitores de tela (`aria-label`, `role`, contrastes).
4. **Performance Visual:** Otimização de renderização, LCP/FID, eliminação de layouts shifts (CLS).
5. **Integração de Contratos:** Consumo seguro de dados providos pela camada de Backend.
